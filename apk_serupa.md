# 📱 Referensi APK Aplikasi Berhenti Merokok

Berikut beberapa APK/aplikasi serupa yang dapat dijadikan referensi untuk proyek **Berhenti Merokok**:

| Nama Aplikasi    | Fitur Relevan                                                                                        | Link                                                                                         |
| :--------------- | :--------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------- |
| **SmokingYou**   | Offline-first, open source, pelacakan kebiasaan, pengingat, rencana pengurangan bertahap, data lokal | [F-Droid](https://f-droid.org/zh_Hant/packages/com.smokingtracker/)                          |
| **TrackLess**    | Offline & privat, pelacak kebiasaan, timer pantang, tonggak kesehatan, backup JSON lokal             | [GitHub](https://github.com/poorangryman/trackless-public)                                   |
| **Quitter**      | Fokus privasi & offline, pelacak kebiasaan, jurnal, pengingat, tanpa akun/internet                   | [F-Droid](https://fdroid.gitlab.io/fdroid-website/zh_Hant/packages/com.quitter.app/)         |
| **SmokeStop**    | Manajemen target/impian, fitur “Savings Goals”, progres tabungan dari uang rokok                     | [Google Play](https://play.google.com/store/apps/details?id=com.smokestop.tracker)           |
| **Quitchi**      | Manajemen target/impian, fitur “Wishlist” untuk target personal dari uang yang dihemat               | [Google Play](https://play.google.com/store/apps/details?id=com.quitchi.app)                 |
| **EasyQuit**     | Data lokal & tanpa login, mode pengurangan bertahap, statistik penghematan, lencana motivasi         | [Google Play](https://play.google.com/store/apps/details?id=com.herzberg.easyquitsmoking)    |
| **Kwit**         | Pendekatan CBT, pelacakan progres, penghematan uang, jurnal perjalanan                               | [APKFab](https://apkfab.com/zh/kwit-quit-smoking-for-good-smoking-cessation/fr.kwit.android) |
| **Quit Tracker** | Mencatat uang yang dihemat, waktu hidup yang didapat kembali, linimasa kesehatan                     | [APKMirror](https://www.apkmirror.com/apk/despdev/quit-tracker-stop-smoking/)                |
| **SmokeFree**    | Statistik rinci, uang yang dihemat, indikator kesehatan, buku harian keinginan merokok               | [APKFab](https://apkfab.com/zh/smokefree-quit-smoking-slowly/com.motivebite.smokefree.free)  |
| **QuitNow!**     | Komunitas, chat dengan mantan perokok, kursus berhenti merokok langkah demi langkah                  | [Google Play](https://play.google.com/store/apps/details?id=com.EAGINsoftware.dejaloYa)      |

## 💡 Rekomendasi Referensi Utama

- **SmokingYou** dan **TrackLess** → paling dekat untuk arsitektur **offline-first** dan penyimpanan data lokal.
- **SmokeStop** dan **Quitchi** → referensi fitur **impian/target** dan pengelolaan tabungan dari uang rokok.
- **EasyQuit** dan **SmokeFree** → referensi statistik, penghematan, dan motivasi pengguna.

> Catatan: tautan di atas mengarah ke halaman resmi/komunitas seperti F-Droid, GitHub, Google Play, APKFab, dan APKMirror. Untuk kebutuhan referensi pengembangan, utamakan sumber resmi atau open-source.
